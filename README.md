# AI Student Performance Predictor

An intelligent full-stack educational analytics platform that bridges software development with data science and AI.

## Overview
- **Data Ingestion:** Upload and track student quiz scores, practice tasks, classroom participation, and attendance.
- **Syllabus-Aware AI Predictions:** Analyze upcoming syllabus milestones against student weak areas to forecast performance and recommend personalized practice.
- **Automated Reporting:** Generate comprehensive monthly student development reports (including attendance, academic ratings, soft skills, parent notes, and actionable next steps).
- **Quiz Integration:** Wayground quiz score synchronization and automated imports.

## Architecture
- **Frontend:** Next.js / React (UI/UX dashboard)
- **Backend & AI Engine:** Python (FastAPI / Machine Learning & LLM pipeline)
- **Database:** PostgreSQL
